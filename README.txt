BOVI-DENMARK FRONTEND DEMO
==========================

Files:
- index.html: website structure and Danish content
- style.css: responsive layout, colors, typography and effects
- script.js: mobile navigation, current year and contact email form
- assets/dairy-cows-hero.png: generated hero image

HOW TO RUN
1. Extract the ZIP folder.
2. Open index.html in Chrome, Edge, or Firefox.
3. Internet is needed for Google Fonts and the additional Unsplash images. The generated hero image is stored locally.

NOTES
- This is a frontend-only demo built with HTML, CSS and vanilla JavaScript.
- The contact form opens the visitor's default email application. It does not save submissions to a server.
- Some secondary photos are loaded from Unsplash and will fall back to the local hero image if they fail to load.
- Replace placeholder copy, images and contact information as needed before publishing.
